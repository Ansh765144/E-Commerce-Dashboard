# E-Commerce-Dashboard

# NOTE: This repository contains only project documentation having dashboard outputs, and analysis results created as part of an academic Data Analytics project. The project was created using free  14 day trial provided by tableau, so full access to the project is restricted.
# The dataset used was "O List Brazil Ecommerce Dataset"

Project Overview
This project focuses on analyzing e-commerce sales, customer purchasing behavior, logistics performance, and transaction health using Tableau dashboards. The objective was to transform raw business data into meaningful visual insights that support data-driven decision-making.

Tool Used
1 Tableau
2 MySQL 

Dashboards Included
# 1. Revenue Performance Dashboard
Analyzes revenue trends over time.
Compares monthly revenue with order volume.
Identifies high-performing product price tiers.
Highlights seasonal demand patterns.
# 2. Operational Overhead Dashboard
Examines shipping costs and freight ratios.
Identifies categories with higher logistics expenses.
Evaluates the impact of shipping costs on profitability.
# 3. Fulfillment Quality Dashboard
Visualizes delivery performance across regions.
Tracks order fulfillment trends.
Highlights operational strengths and improvement opportunities.
# 4. Transaction Health Dashboard
Analyzes order approval times.
Evaluates customer payment preferences.
Identifies transaction bottlenecks affecting customer experience.
